# Fragenkatalog — Cattery App

**Wie das hier funktioniert:**
Jede Frage lässt sich mit **Ja/Nein**, einer **Zahl** oder **einem kurzen Satz** beantworten.
Einfach die Nummer und die Antwort notieren — z. B. „8. 2x täglich", „14. ja", „17. 95 g".

⭐ = wichtig. Wenn die Zeit knapp ist: **nur die ⭐-Fragen beantworten**, damit reicht es, um anzufangen.
„Weiß nicht" oder „egal" ist eine völlig gültige Antwort. Nichts muss ausgefüllt werden.
